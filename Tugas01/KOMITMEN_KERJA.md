Komitmen Kerja

    Dokumen ini berisi komitmen pribadi saya dalam mengelola repository dan mengerjakan tugas Rekayasa Perangkat Lunak selama semester berlangsung.

1. Waktu Respons

    Saya berkomitmen untuk memeriksa repository, tugas, dan komunikasi yang berkaitan dengan pekerjaan secara berkala. Jika terdapat pekerjaan atau masukan yang perlu ditindaklanjuti, saya akan berusaha memberikan respons dalam waktu yang wajar.

2. Cara Berkomunikasi

    Saya akan menggunakan bahasa yang sopan, jelas, dan relevan ketika berkomunikasi mengenai tugas atau pekerjaan. Jika terdapat perbedaan pendapat, saya akan menyampaikan alasan berdasarkan fakta, kebutuhan tugas, dan bukti yang tersedia.

3. Aturan Branch dan Review

    Untuk perubahan yang cukup besar, saya akan menggunakan branch terpisah agar perubahan dapat diperiksa sebelum digabungkan ke branch utama. Perubahan yang berkaitan dengan tugas akan diperiksa kembali sebelum dianggap selesai.

4. Definisi "Selesai"

    Sebuah pekerjaan dianggap selesai apabila isi tugas telah memenuhi instruksi yang diberikan, sudah diperiksa kembali, file dapat dibuka atau digunakan dengan baik, serta dokumentasi yang diperlukan telah diperbarui.

5. Menyikapi Perbedaan Pendapat

    Jika terdapat perbedaan pendapat mengenai solusi atau cara pengerjaan, saya akan membandingkan alternatif berdasarkan kebutuhan, bukti, risiko, dan tujuan tugas. Keputusan akhir akan dipilih berdasarkan alasan yang paling relevan terhadap kebutuhan pekerjaan.

6. Kejujuran Kontribusi

    Saya akan mencatat kontribusi yang benar-benar saya kerjakan dan tidak mengklaim pekerjaan orang lain sebagai pekerjaan pribadi. Jika menggunakan referensi, aset, kode, atau bantuan dari pihak lain, saya akan mencantumkan sumber atau menjelaskan penggunaannya sesuai kebutuhan.

7. Dokumentasi

    Saya berkomitmen untuk menjaga dokumentasi repository agar tetap jelas dan mudah dipahami. Setiap tugas akan ditempatkan pada folder yang sesuai dan perubahan penting akan dicatat melalui commit yang memiliki pesan yang jelas.

8. Penggunaan Git

    Saya akan menggunakan Git secara bertahap selama pengerjaan tugas, bukan hanya membuat satu commit besar ketika seluruh tugas sudah selesai. Setiap commit akan menggambarkan perubahan yang dilakukan.
