Contributing Guide

    Terima kasih jika ingin memberikan kontribusi pada repository ini.

    Repository ini merupakan repository tugas pribadi untuk mata kuliah Rekayasa Perangkat Lunak. Kontribusi dari orang lain tetap harus mengikuti aturan berikut.

1. Branch

    Jangan melakukan perubahan langsung pada branch utama jika perubahan cukup besar.

    Gunakan format branch:

    `feature/nama-perubahan`

    Contoh:

    `feature/perbaikan-readme`

2. Commit

    Gunakan pesan commit yang singkat dan menjelaskan perubahan.

    Contoh:

    `docs: update README`

    `docs: add AI policy`

    `docs: add task 01 report`

3. Pull Request

    Jika tersedia akses untuk membuat Pull Request, jelaskan:

    - perubahan yang dilakukan;
    - alasan perubahan;
    - file yang terpengaruh;
    - hasil pemeriksaan.

4. Pemeriksaan

    Sebelum Pull Request digabungkan, perubahan harus diperiksa untuk memastikan tidak merusak struktur repository atau menghilangkan file tugas.

5. Komunikasi

    Sampaikan saran atau perubahan dengan bahasa yang sopan dan berdasarkan alasan yang jelas.

6. Kejujuran Kontribusi

    Kontributor harus menjelaskan bagian yang benar-benar dikerjakan. Kontribusi tidak boleh diklaim sebagai pekerjaan orang lain.
